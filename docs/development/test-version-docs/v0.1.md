# melo-rx v0.1 — Manual Testing Guide

This guide walks you through verifying every endpoint and behaviour implemented in v0.1 from scratch. Run each command in sequence; expected output is shown beneath each step.

---

## Prerequisites

- Docker running
- Node.js 22+ and pnpm 9+ installed
- Repository cloned and at the repo root
- **RxNorm Full Release** unzipped, with `RXNCONSO.RRF` and `RXNREL.RRF` placed at `pipeline/resolver/raw/`
(required for the class-rule seed; RxNorm is distributed under the UMLS Metathesaurus License Agreement and is not redistributed in this repo — the `raw/` directory is gitignored)

To obtain it:

```bash
# Request a free UMLS license at https://uts.nlm.nih.gov/uts/signup-login
# Download the RxNorm Full Monthly Release from:
#   https://www.nlm.nih.gov/research/umls/rxnorm/docs/rxnormfiles.html
# Extract the files we need:
mkdir -p pipeline/resolver/raw
unzip -j -o /path/to/RxNorm_full_MMDDYYYY.zip "rrf/RXNCONSO.RRF" "rrf/RXNREL.RRF" -d pipeline/resolver/raw
```

`RXNCONSO.RRF` supplies the ingredient → RxCUI index and ATC codes; `RXNREL.RRF` supplies the brand-name ↔ ingredient `tradename_of` graph.

### 4b. ONCHigh class rules + RxNorm drug_concept enrichment

This step seeds the 14 ONCHigh class-level rules into `drug_class_interaction` and enriches `drug_concept` with RxCUI, class labels, ATC code, and brand names — all resolved from RxNorm (RXNCONSO + RXNREL). Class rules remain class-level and are expanded to concrete pairs at query time — per architecture rule #9, they are never pre-materialised.

```bash
pnpm db:seed:classes
```

Expected log output (pretty-printed in dev):

```
Loaded 14 ONCHigh class rules (1 deferred)
Loaded RxNorm ingredient index (22083 entries)
Loaded RxNorm identifier index (~53000 ingredient RxCUIs with ATC and/or brand names)
drug_concept: inserted 82, classes-updated 4, identifiers-updated <n>, unresolved 1
Drugs without RxNorm ingredient match { unresolved: [ "St John's wort" ] }
drug_class_interaction: inserted 20, skipped 0
```

Loading the identifier index streams the 523MB `RXNREL.RRF` and takes roughly 5–10 seconds; this happens once per seed run.

Notes:

- 14 source rules → 20 `drug_class_interaction` rows (rules 11, 25, 27 each expand into 3 sub-class rows).
- Rule 21 (QT × QT) is deferred — it requires an authoritative QT-prolonger list (CredibleMeds) and is handled in a future source.
- `St John's wort` is expected to fail ingredient resolution — RxNorm indexes it as Hypericum perforatum variants. The seed logs this and continues.
- Of 97 unique drugs referenced across the rules, ~92 resolve to a primary ATC code and ~95 pick up at least one brand name.

Verify the class rules:

```bash
docker exec $(docker compose ps -q postgres) psql -U melo -d melo_rx \
  -c "SELECT COUNT(*) AS rows, COUNT(DISTINCT class_a) AS object_sides FROM drug_class_interaction;"
```

Expected:

```
 rows | object_sides
------+--------------
   20 |           13
```

Spot-check a high-severity rule:

```bash
docker exec $(docker compose ps -q postgres) psql -U melo -d melo_rx \
  -c "SELECT class_a, class_b, severity FROM drug_class_interaction WHERE class_a ILIKE '%ergot%';"
```

Expected: 3 rows (protease / macrolide / azole CYP3A4 inhibitor sub-classes), each `contraindicated`.

Verify `drug_concept` enrichment now carries RxCUI + class labels:

```bash
docker exec $(docker compose ps -q postgres) psql -U melo -d melo_rx \
  -c "SELECT rxcui, name, drug_class FROM drug_concept WHERE name IN ('simvastatin','Ritonavir','fluvoxamine') ORDER BY name;"
```

Expected (simvastatin picked up its class label, ritonavir picked up two, fluvoxamine picked up two):

```
  rxcui  |     name     |                               drug_class
---------+--------------+-------------------------------------------------------------------------
  42355  | fluvoxamine  | {Serotonergic antidepressants (SSRIs/SNRIs/related),Strong CYP1A2 inhibitors}
  85762  | Ritonavir    | {CYP3A4 inhibitors (protease inhibitors),HIV protease inhibitors}
  36567  | simvastatin  | {Simvastatin and lovastatin}
```

(Exact ordering inside the array and exact spelling of the RxNorm `name` field may vary — RxNorm's canonical casing is used.)

Verify brand names and ATC codes are populated on `identifiers`:

```bash
docker exec $(docker compose ps -q postgres) psql -U melo -d melo_rx \
  -c "SELECT rxcui, name, identifiers->'atc' AS atc, identifiers->'brand_names' AS brands FROM drug_concept WHERE rxcui IN ('36567','85762','343047') ORDER BY name;"
```

Expected:

```
  rxcui  |    name     |    atc     |                   brands
---------+-------------+------------+---------------------------------------------------
 343047  | Atazanavir  | "J05AE08"  | ["Evotaz","Reyataz"]
 85762   | Ritonavir   | "J05AE03"  | ["Kaletra","Norvir","Technivie","Viekira", ...]
 36567   | simvastatin | "C10AA01"  | ["Flolipid","Juvisync","Simcor","Vytorin","Zocor"]
```

(Exact brand-name lists change with each RxNorm release.)

Only drugs referenced in the ONCHigh class rules are enriched by this seed. Drugs seeded in step 4a that are not also in any class rule — for example `warfarin` (11289) — retain the empty `identifiers` shape from the curated seed. Broadening identifier enrichment to cover every `drug_concept` row is a future step.

## 10. Interactions endpoint

### 10.1 Known interaction by RxCUI

```bash
curl -s "http://localhost:3000/v1/interactions?drug1=5640&drug2=29046" | jq .
```

Expected response shape (check these fields):

- `data.interactions[0].severity` → `"moderate"` (ONCHigh "significant" → canonical "moderate")
- `data.interactions[0].sources` → array with 1 ONCHigh citation
- `disclaimer` → present and non-empty
- `meta.version` → `"0.1.0"`

Full expected response:

```json
{
  "data": {
    "drug1": { "rxcui": "5640", "name": "ibuprofen", "classes": [] },
    "drug2": { "rxcui": "29046", "name": "lisinopril", "classes": [] },
    "interactions": [
      {
        "severity": "moderate",

            "url": "https://www.ncbi.nlm.nih.gov/pmc/articles/PMC3817532/",
```
